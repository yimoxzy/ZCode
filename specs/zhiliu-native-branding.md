# 织流原生窗口与启动标识

织流构建统一使用现有 SaaS `desktop/assets/icon.svg` 对应的蓝色标识，打包资源由 `build/zhiliu` 保存；上游构建继续使用原资源。

Main 拥有窗口和系统图标。打包态沿用 resources 文件名，由打包配置选取品牌资源；开发态从品牌目录读取。云窗口接收 Main 提供的图标路径，不接受网页传入图标或系统权限。

Vite 在 HTML 进入浏览器之前按构建身份选择启动图标、favicon 和页面标题，避免 React 就绪之前闪现上游标识。原始模板及启动事件名保持兼容。辅助权限页运行时的标题也遵循相同身份；这不代表 Computer Use 能力已经开放。

原生关于窗口以织流为应用品牌，写明平台统一模型、账号和积分，本地授权网关未接通时本地推理不可用；许可段保留上游项目署名。安装器详细信息使用实际产品名称，内部宏名和数据目录保护契约保持不变。

验收：安装包、exe、卸载器、快捷方式、托盘、任务栏、云窗口、启动HTML和就绪后UI均使用织流标识；深浅主题中清晰。原ZCode安装及其系统入口不受影响；个人模型配置限制保持生效。HTML变换未开启品牌开关时原样返回；真实安装程序检查标题、品牌图标及配置边界，截图留证。
