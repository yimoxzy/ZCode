# 织流反馈入口

织流桌面帮助菜单与工作模式栏的问题反馈复用织流 SaaS 的普通用户反馈页。Main 是地址和窗口的唯一所有者：从可信云地址构造固定 `#/feedback?source=desktop&app_version=…` 路由，不接受 renderer 提供 URL、Token、日志、文件路径或会话正文。上游反馈工单服务继续关闭。

没有云窗口时按既有沙箱规则打开；已有同源窗口时仅显式反馈命令允许导航到固定反馈 hash。一般“云 Agent”命令继续只恢复/聚焦现有窗口，不能重载登录或草稿。反馈 hash 使用同页导航保留 sessionStorage，网页负责登录、空间权限、填写、诊断预览与确认提交；桌面不复制登录状态到本地 Host。

用户只有确认后才提交反馈；当前桥不收集或上传本机日志、截图、文件和对话。本机日志导出仍是独立的用户操作。Web 和桌面反馈进入织流后台统一处理，普通用户不能打开管理员反馈中心，也不能读取内部处理备注或其他租户记录。

验收：所有客户端反馈入口执行 `OpenFeedback`，打开固定同源普通反馈页；同源页面的 hash 导航保留登录和草稿；上游构建保留原反馈行为；远端页没有 preload/Node/RPC 权限。服务不可达时显示可重试错误，不泄露页面参数。
