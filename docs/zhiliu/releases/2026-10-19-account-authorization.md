# 2026-10-19：3.15.3 系统浏览器授权与退出

本批把桌面账号登录改为系统浏览器核码授权。用户在客户端点击「登录织流」，浏览器已登录时确认连接码、账号和空间；未登录时先在织流网页完成登录，再批准桌面请求。客户端不提供密码、模型 Key 或上游地址输入。保留完整 ZCode fork 与官方上游关联，不替换其官方 OAuth 实现，不接入官方账号或服务。

本记录区分已完成的模块验证与最终发布验收。构建、服务器部署、安装包摘要及实际安装结果尚待发布负责人补充；本页不将源码完成描述为3.15.3已安装。

## 账号与云窗

Main 通过 PKCE S256、Ed25519 签名和一次性交换取得独立桌面授权，并使用系统 safeStorage 加密保存。它独占凭据和授权代次；本地 UI 只取得身份显示，不读取浏览器 Cookie，不取得桌面登录 Token。

重启后从安全存储恢复，并向服务端实时校验授权、设备和当前成员权限；普通账号状态缓存至多60秒，进入云窗及取得文件连接身份前再次实时检查。批准时使用的浏览器会话与交换后的桌面会话独立，浏览器退出不会直接登出客户端。

云工作台保持按 origin 隔离的无特权窗口，无 Node、preload 或本机 RPC。Main 生成60秒有效的单次 bootstrap ticket，送到固定同源接入页，网页先移除地址中的票据，再换取关联桌面授权的独立网页会话。关闭云窗后重开，桌面授权仍有效时无需重复输入密码。

登录不选择目录、不启动文件桥，不代表电脑已经在线。「连接电脑」仍使用独立 Host grant、系统目录选择和每次操作/结果的本机确认；账号与文件连接复用设备密钥，但不共享权限范围。模型与积分由 SaaS 统一管理。

## 退出与迟到结果

「退出登录」先显示原生确认，默认选择「取消」。提醒明确说明网页将无法控制这台电脑、本机待确认操作会取消、云端任务可能继续运行。

确认后立即使旧代次失效、暂停文件连接与审批，串行清理 Host 和账号凭据，撤销服务端桌面授权及关联网页会话，再关闭并清理隔离云窗。离线时仍完成本机清理；远端撤销未获确认时明确提示去网页撤销设备。清理失败不能报告完整退出成功。

重复登录复用进行中的请求。取消或退出之后，迟到交换会尽力撤销；已开始的旧凭据保存按 token 比较后串行清除，不能删除新登录记录。旧登录命令返回本次取消结果，不能借新账号状态继续打开云窗。已开始的云窗加载与清理使用同一串行队列，避免退出后重新出现登录窗口。
