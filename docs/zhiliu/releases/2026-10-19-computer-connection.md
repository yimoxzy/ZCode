# 2026-10-19：电脑连接与云 Agent 文件任务

本批增加网页识别本人电脑及云 Agent 文件工具桥。用户登录织流，在客户端点击“连接电脑”，核对网页中的连接码及当前空间，再通过系统选择器授权工作目录。网页设置中的“桌面设备”显示在线及目录就绪，聊天时选择该电脑；云模型请求文件工具后，本机逐次批准操作，并预览要发送的结果。

## 实现与隔离

- SaaS 新增窄 Host grant，使用 Ed25519、PKCE、一次交换及签名心跳。grant 不访问普通业务 API，不包含上游 Key；退出、切空间或撤销后不能接受新工具。
- Main 持有系统安全存储、原生选择器和审批窗口；文件轮询、执行和加密 journal 归已有窗口 Host，专用 MessagePort 只由 Main 持有。云网页仍无 Node/preload/本机桥。
- 每次进程启动重新选择目录；只允许目录内不超过64 KiB的UTF-8文本读写。路径、链接、凭据及并发修改守卫拒绝不符合策略的请求。
- 暂停、断开、Host关闭或新代次使旧审批失效。凭据写删串行，端口替换串行且只接纳最新代次；停止失败或超时不阻断其他Host退出阶段。
- 执行前持久化claim/executing，断线只补传用户已同意的结果；不因重试重放文件操作。崩溃或执行结果不明确时返回失败说明。
- 模型推理、Run、企业权限和积分计费留在SaaS；本地Host不会启动未接推理计费网关的ZCode CLI。
