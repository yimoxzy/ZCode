## 本批实际行为

- 首屏提供“登录云 Agent”；云窗口复用 SaaS 账号、空间权限和现有积分链。
- 个人模型、API Key、上游地址、供应商导入和连接测试入口关闭。Host 的供应商配置 RPC、配置来源和本地执行准入也拒绝个人模型；旧配置和环境变量不会开放本地推理。
- 本地项目保留现有窗口与 Host 结构；不启动 bundled CLI。界面明确显示本地 Agent 未开放。
- 云页面在独立、按 origin 隔离的窗口中运行，无 Node、preload 或本机 RPC 桥；关闭云窗口后本地窗口仍存活。
- 应用 ID、profile、数据根和日志隔离；不扫描或导出原 ZCode 的模型配置，不注册其协议或文件管理器入口。
- 本机原 ZCode、旧织流测试版均保留。安装前后上游协议和文件管理器入口仍指向原 ZCode。

当前技术包通过本机安全隧道连接服务器。客户分发前须配置正式 HTTPS 地址并重建；安装包没有附带运维凭据或上游 Key。云页面登录不等于本地 Host 获得 OAuth grant。

## 未完成与开放条件

1. 平台 OAuth/PKCE 或设备授权交换、系统凭据存储、撤权及空间 scope 校验。
2. 本地任务级推理网关：服务端路由、累计 usage、预占结算、限额、断线对账和退款关联。平台上游 Key 始终留在服务器。
3. 本地 CLI、Skill/MCP 与工具执行；必须先完成前两项并通过绕过与计费测试。
4. Web 查看本地历史、下发任务、双向会话与跨端追加指令；需显式共享授权和织流 broker，不接入上游官方 relay。
5. 本机目录/终端审批、Desktop Tool Broker、离线恢复、远程取消和设备撤销的端到端验收。账号授权不授予任意本机操作。
6. Computer Use、操作系统级沙箱、App、小程序和 macOS/Linux 整包验收。
7. 完整织流视觉、正式 HTTPS、签名、安装升级和客户分发。云会话当前随窗口关闭结束，未提供本地授权单点登录。

下一批先实施平台授权与计费契约，再开放本地 Agent；本批不通过用户自带 Key 绕过这些条件。具体契约见织流 SaaS `docs/architecture/15-desktop-inference-gateway-contract-20261019.md`。

回退本技术版可以关闭或卸载独立“织流 SaaS”，不会改动云服务、原 ZCode 或旧织流测试版；保留用户数据前不执行数据目录清理。
